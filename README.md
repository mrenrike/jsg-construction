## 🚀 Como Executar Localmente

Caso queira rodar um servidor web local na sua máquina:
1. Abra o terminal PowerShell nesta pasta:
   `powershell
   cd C:\Users\USER\.gemini\antigravity\scratch\jsg-construction
   `
2. Inicie o servidor HTTP nativo:
   `powershell
   python -m http.server 8080
   `
3. Abra no navegador:
   * Website: [http://localhost:8080/](http://localhost:8080/)
   * Brand Guide: [http://localhost:8080/brandguide.html](http://localhost:8080/brandguide.html)
   * Artigos: [http://localhost:8080/articles.html](http://localhost:8080/articles.html)
